## :dart: O guia para alavancar a sua carreira

> AdonisJS é um framework Node.js "TypeScript-first" para criar aplicações web full-stack e servidores de API: roteamento, ORM (Lucid), validação (VineJS), autenticação, filas, e-mail e testes já vêm resolvidos, sem você precisar escolher e colar dezenas de bibliotecas soltas. Mantido desde 2015 por Harminder Virk e uma equipe internacional, chegou à versão 7 em 2026 com geração de tipos ponta a ponta e integração nativa com Inertia e HTMX. Este guia reúne documentação oficial, cursos, ferramentas do ecossistema, projetos práticos e uma seção sobre como usar IA no dia a dia com o framework — tudo verificado, para quem já programa em JavaScript/TypeScript e quer um back-end produtivo sem reinventar a roda.

## 🤖 IA na prática

AdonisJS é "batteries-included": as convenções fortes do framework (estrutura de pastas fixa, injeção de dependência, Ace para gerar código) tornam mais fácil para um assistente de IA prever onde cada coisa deve ficar — desde que você dê o contexto certo.

**Para aprender**
- Peça para a IA **explicar um trecho de código gerado pelo `node ace make:controller`** linha a linha, incluindo por que o AdonisJS usa injeção de dependência ali.
- Cole um erro de validação do VineJS e peça para a IA mostrar como corrigir o schema sem enfraquecer a validação.
- Peça exercícios práticos sobre um tópico específico (migrations, relacionamentos no Lucid, guards de autenticação) com gabarito comentado.

**Para trabalhar**
- Use [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) ou [Claude Code](https://code.claude.com/docs/en/overview) para gerar controllers, validators e migrations seguindo as convenções do Ace, e depois rode `node ace make:*` para conferir se a IA seguiu o padrão esperado pelo framework.
- A documentação oficial é publicada também em Markdown puro (acrescente `.md` a qualquer URL de `docs.adonisjs.com`), o que facilita colar o conteúdo certo no contexto do seu assistente de IA.
- Depois de aceitar uma sugestão, rode os testes com Japa (`node ace test`) e o `tsc --noEmit`: como o framework é fortemente tipado, o compilador pega boa parte dos erros que a IA comete.

**Limites e boas práticas**
- IA erra APIs de pacotes menos populares do ecossistema (drivers de Ally, addons de terceiros). Confirme sempre no repositório oficial do pacote.
- Ela tende a "inventar" opções de configuração que existiam em versões antigas (v5/v6) mas mudaram na v7. Confira a versão instalada no seu `package.json` antes de aplicar uma sugestão.
- Não cole variáveis de ambiente, chaves de API ou dados de clientes em ferramentas de IA sem a política da sua empresa.

Leitura recomendada direto da equipe do framework sobre o tema:
- [How I'm teaching AI to write AdonisJS the way I would](https://adonisjs.com/blog/teaching-ai-to-write-adonisjs) — O criador do AdonisJS explica como vem ajustando o framework e a documentação para funcionar melhor com assistentes de IA.
- [Batteries-included frameworks in the era of AI](https://adonisjs.com/blog/frameworks-in-the-era-of-ai) — Por que frameworks com convenções fortes tendem a se dar melhor com código gerado por IA.
- [Introducing codegen command and application warmup phase](https://adonisjs.com/blog/codegen-and-application-warmup) — Novo comando do Ace que gera tipos e arquivos de índice automaticamente, reduzindo erros de tipagem (inclusive os cometidos por IA).
